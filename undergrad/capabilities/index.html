FIVE CAPABILITY DOMAINS

五大能力：从兴趣到完整项目

十二类作品产出背后，是五个可以互相组合的能力领域。学生不需要一开始决定终身方向，但需要在项目中逐渐形成主线与协作能力。

SYSTEM

五个领域不是五个互不相干的专业

视觉语言与策略传播

品牌、出版、动态设计与视觉运营。

信息体验与应用设计

界面、信息图表、数据可视化与数字传播。

3D 虚拟艺术制作

建模、虚拟叙事、AR/VR/MR 与沉浸体验。

多媒介与装置艺术

影像、投影、声音、材料、空间与表演。

AIGC 创意计算机与互动机械

生成算法、创意编程、物理计算、机器人与可穿戴。

PROJECT LOOP

所有领域共享一条项目闭环

  1. 观察与调研

    从兴趣或真实问题建立证据。

  2. 概念与方法

    决定项目立场、受众与实验方式。

  3. 原型与测试

    让想法通过画面、材料、代码或空间被验证。

  4. 迭代与交付

    依据反馈调整并形成完整呈现。

  5. 复盘与表达

    说明取舍、个人贡献与下一步。

FOUNDATION

基础能力决定跨媒介是否真的成立

  • 观察、造型、构图、色彩、字体与视觉叙事。
  • 调研方法、设计史、批判性思维与概念发展。
  • 常用设计软件、数字制作工具与原型能力。
  • 讨论、协作、展示和书面表达。

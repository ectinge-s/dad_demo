MEDIA

媒介之间必须形成关系

影像与投影

用画面、光与表面改变空间感知。

声音艺术

通过声场、节奏和位置组织情绪与注意力。

材料装置

让材料特性、结构与尺度参与表达。

行为与表演

通过身体、动作、现场与观众关系传达观念。

INSTALLATION LOOP

从桌面草图走到真实空间

  1. 场地观察

    记录尺度、光线、电力、声音、动线与安全限制。

  2. 材料测试

    小样验证结构、表面、投影和声音效果。

  3. 空间原型

    模拟观众视角、进入顺序与互动方式。

  4. 布展复盘

    现场校准并记录体验与反馈。

OUTPUTS

可形成的代表产出

  • 影像与投影装置
  • 声音艺术
  • 材料与空间装置
  • 实验表演
  • 音画互动与现场展示

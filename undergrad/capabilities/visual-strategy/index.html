PROJECT EXAMPLE

一个品牌项目应包含什么

  1. 调研

    理解受众、场景、竞品与文化语境。

  2. 策略

    确定定位、核心信息与视觉原则。

  3. 系统

    建立字体、色彩、图形、版式和内容规则。

  4. 触点

    在包装、界面、广告、出版或空间中验证一致性。

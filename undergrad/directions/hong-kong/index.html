HONG KONG

香港：设计、创意媒体与系统创新

香港相关本科分布在设计学院、创意媒体学院与跨学科学院。项目名称相近时，应比较课程归属、技术深度与作品集语境。

3 主要项目类型
组合 学术与作品并行
变化 项目名称持续更新

本页内容

  1. 设计与交互
  2. 创意媒体与艺术科技
  3. 跨学科与数字未来
  4. 同一项目需要三种解释能力

TYPE 01

设计与交互

适合希望从用户、信息、产品、服务或沉浸体验进入设计的学生。

PolyU Design

本科设计计划覆盖 Interaction Design、Information Design 等方向；Media Design 正在向 Immersive Media and Game Design 调整，目前处于审批阶段。

项目重点

作品需要呈现调研、设计方法、原型、测试与系统表达，而不只是界面成品。

TYPE 02

创意媒体与艺术科技

适合希望连接影像、声音、动画、游戏、编程、电子装置与媒体艺术的学生。

CityU School of Creative Media

Creative Media BA、New Media BAS 与 Creative Media BSc 分别提供艺术、艺术科学与技术强度不同的入口。

Hong Kong Baptist University

可关注创意艺术、电影、媒体与跨媒介相关方向，并结合目标专业建立申请组合。

TYPE 03

跨学科与数字未来

这类项目把设计作为解决复杂问题的方法，需要同时证明学术基础、系统思考与实践能力。

HKU

Humanities and Digital Technologies、Global Creative Industries 等方向连接数字人文、创意产业与跨学科实践。

HKUST

Integrative Systems and Design 以项目制、系统思维和技术创新为核心；学院项目命名正在更新，选校时根据招生目录确定目标方向。

APPLICATION

同一项目需要三种解释能力

  • 向设计项目解释用户与系统。
  • 向创意媒体项目解释媒介与个人表达。
  • 向跨学科项目解释技术、社会问题与协作。
  • 面试准备要能口头还原调研、取舍和个人贡献。

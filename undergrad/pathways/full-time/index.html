01 / 学院

把国际课程、作品集与申请放进同一条培养链

SFK 于 2012 年成立，2016 年加入新东方教育科技集团，并在北京、上海、广州、深圳、成都、杭州、武汉、南京、苏州、重庆、西安、郑州与东京形成教学网络。学院以“成就学员、专注、尽责”为共同追求，持续引入国际艺术课程、海外教授与面向申请结果的课程产品。

数字艺术与设计全日制学院成立于 2021 年，面向计划申请英国、澳大利亚、新加坡等英联邦艺术与设计本科的学生，把 A-Level、BTEC、国际 1+2、雅思、专业基础、作品集与留学申请组织在同一学习周期中。

DAD 导师参与 A-Level 图形传播与通识课程，把国际课程和专业项目并行推进，让学生不必在学术课程、作品集和申请节点之间反复切换。

03 / 环境

专属学习空间，让长期项目可以稳定发生

A-Level 数字艺术与设计全日制拥有独立楼层，空间同时服务课堂教学、自主学习、小组讨论与作品存放。安全、安静和设备条件共同支撑持续创作。

课堂区

宽敞的教室与教学设备支持讲授、演示、媒介实验和课堂互动。

自习区

相对安静的学习区域便于完成调研、草图、软件练习和项目整理。

讨论与展示

灵活空间支持小组讨论、阶段讲评、作品陈列和公开展示。

日常保障

门禁管理与个人储物柜让材料、工具和长期项目更容易被妥善保存。

04 / 学习路径

从入学评估到背景提升，六个阶段连续推进

全日制并不是把课程简单叠加，而是让评估、教学、管理、审核、申请与背景提升彼此衔接。每个阶段都有明确的参与者、产出与下一步行动。

  1. 入学与定位

    通过入学作品评估、导师点评和学习计划，明确专业兴趣、基础差距、目标国家与时间安排。

    • 入学作品评估
    • 导师点评
    • 个人学习计划
    • 开学典礼

  2. 课程教学

    根据路线进入国际课程与专业课程，把基础技法、潜力开发和项目创作放在同一进度中。

    • A-Level 艺术
    • BTEC 作品集
    • 国际 1+2 本科
    • 日本通识艺术
    • 基础技法
    • 潜力开发

  3. 班级与教务管理

    围绕出勤、课表、作业、项目节点与学习状态进行日常跟踪，并保持稳定的家校沟通。

    • 学生服务与管理
    • 课程安排
    • 项目进度跟踪
    • 家长反馈
    • 家长会
    • 问题协调

  4. 作品集审核

    从思维评估到季度 Critique，再到教研终审，让项目在递交前经历多轮讨论和迭代。

    • 思维评估
    • 季度 Critique
    • 教研终审
    • 版面与递交质量

  5. 留学申请

    选校、文书、申请节奏、面试训练与海外服务和作品集进度同步推进。

    • 文书写作
    • 申请规划
    • 面试训练
    • 海外服务

  6. 背景提升

    通过学院活动、学生展览、实习竞赛和名校冬夏校，把课堂能力放进真实场景。

    • 学院活动
    • 学生展览
    • 实习与竞赛
    • 名校冬夏校

05 / 管理

班主任、教务与专业导师共同守住学习节奏

三类角色解决不同问题：班主任关注日常状态与家校沟通，教务负责整体学业进度，专业导师深入项目内容。协作机制让学生既能获得稳定管理，也能保留创作探索的空间。

班主任

每个 A-Level 班级配备专属班主任，负责日常出勤、学习状态、班级事务、家校沟通与阶段表现反馈。

  • 出勤
  • 日常状态
  • 班级管理
  • 家校沟通

教务老师

为学生跟踪课程、作业、项目与考试进度，在学术安排、行政执行和沟通之间建立连接。

  • 课程进度
  • 作业项目
  • 考试安排
  • 协同沟通

专业导师

由方向匹配的专业导师负责教学和持续学术支持，深入选题、过程、技术、创意表达与讨论。

  • 选题
  • 研究过程
  • 技术支持
  • 创意呈现

家庭协同

通过日常反馈、阶段总结与家长会，让家庭了解进度、优势与下一阶段目标，形成稳定支持。

  • 进度反馈
  • 阶段总结
  • 家长会
  • 问题解决

06 / 审核

四级审核，让作品在关键节点得到真实反馈

审核由导师、教研团队与海外教授共同参与，覆盖项目从开题到递交的完整过程。反馈被汇总进“艺术阶梯评估报告”，学生和家长可以通过移动端持续查看阶段结果与后续计划。

全国联动审核

学生完成专业输出后，由导师评估并提交；班主任上传全国系统，学科导师与教研团队继续评估并制定下一阶段计划。

海外教授反馈

通过一对一评审、视频评审与书面反馈，让学生在国际教学语境中理解作品的优势和发展空间。

可视化阶段报告

系统将评估结果推送至学生服务账号，学生与家长能够看到阶段表现、项目问题和后续行动。

  1. 开题审核

    确认研究问题、方向、项目范围和推进路径。

  2. 单项目审核

    检查调研、实验、媒介选择、过程证据与迭代逻辑。

  3. 中期审核

    识别完成风险，调整优先级、深度与最终呈现方式。

  4. 排版与递交审核

    统一叙事、项目排序、过程呈现与递交质量。

08 / 国际课堂

用一个假期，进入海外院校的工作室方法

冬夏校和大师课以工作室制展开，学生在短周期内接触海外院校的研究方式、讲评节奏与媒介实验。优秀学生还可以获得教授的学术评价、推荐信和后续发展建议。

工作室 冬校与夏校 从灵感、调研和实验走向完整输出

课程对标海外艺术院校，由来自 UAL、UCL、Oxford、NYU、Parsons、RISD、CCA 等院校的教授参与。学生通过教授讲座、每日一对一辅导、软件教学、媒介实验、个人实践、作品讲评、布展与成果展览完成密集学习。

面向 16 至 18 岁学生的 Portfolio Development 短课以一周密集工作室为例：从艺术家与设计师的创意方法获得启发，通过小组活动、研究和实验发展个人潜力，最终形成包含 sketchbook、设计、调研和多媒介实验的作品组合。

09 / 学院活动

在展览、社会与公开表达中检验课堂能力

学院活动把理论和项目方法带到真实艺术与社会场景。学生在参观、讨论、志愿服务、写生、策展与公开展示中扩大观察范围，也逐步建立批判性思维、审美判断和表达自信。

艺术展览参访

定期进入艺术、设计与科技展览现场，感受媒介和观点的多样性，并在参访后完成讨论与反馈。

公益与志愿行动

在社会协作中理解受众、责任与真实问题，让创作不只停留在个人表达。

户外写生与观察

离开熟悉环境，从城市、自然和现场关系中积累一手视觉资料。

策展与成果展

通过主题策划、作品筛选、空间组织与现场表达，把阶段学习成果转化为面向公众的展示。

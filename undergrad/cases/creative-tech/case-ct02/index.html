匿名案例 CT-02：Buddy Blocks 多人游戏世界

案例以 Buddy Blocks 多人搭建游戏为核心，展示岛屿模型、角色系统、动画、玩法场景与最终视觉，形成完整的游戏世界提案。

PROJECT FOCUS

从玩法概念发展到可见世界

从版面可见，项目将多人搭建机制落实为岛屿场景、角色、动画与不同关卡画面，说明游戏概念如何形成完整视觉提案。

VISIBLE EVIDENCE

版面中可以确认的能力

  • 玩法与世界规则
  • 岛屿和场景建模
  • 角色系统与动画
  • 从过程板到最终设计的完整呈现

ADMISSION RESULT
